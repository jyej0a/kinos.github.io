# 🎉 환영합니다!

**Dark Green Blog**에 오신 것을 환영합니다!

## 블로그 소개

이 블로그는 다음과 같은 특징을 가지고 있습니다:

- 🌿 **다크 그린 테마**: 눈의 편안함을 고려한 어두운 녹색 배경
- 📝 **마크다운 기반**: 간편하게 게시글을 작성할 수 있습니다
- 💬 **Giscus 댓글 시스템**: GitHub Discussions를 활용한 댓글 기능
- 🔍 **검색 기능**: 게시글을 쉽게 찾아볼 수 있습니다
- 📱 **반응형 디자인**: 모바일과 데스크톱 모두 최적화

## 사용 방법

### 게시글 작성하기

1. `pages/` 폴더에 마크다운 파일을 생성합니다
2. Front Matter를 작성합니다:
   ```markdown
   ---
   title: '게시글 제목'
   date: 2025-10-28
   tags: ['JavaScript', 'Web']
   category: 'Development'
   description: '게시글 설명'
   ---
   ```

3. 본문을 작성합니다
4. 변경사항을 커밋하고 푸시합니다

### 코드 블록 예시

```javascript
function greet(name) {
  return `안녕하세요, ${name}님!`;
}

console.log(greet('방문자'));
```
