# 안녕하세요! 👋

오늘부터 블로그를 시작합니다. 

## 블로그를 시작한 이유

평소에 생각했던 것들을 정리하고, 배운 내용들을 기록하고 싶어서 시작하게 되었습니다.

### 앞으로의 계획

- 꾸준히 글쓰기
- 일상적인 생각 공유
- 배운 것들 정리

## 좋아하는 것들

1. ☕ 커피 마시기
2. 📚 책 읽기  
3. 🎵 음악 듣기
4. 🌳 산책하기

## 명언 하나

> 천 리 길도 한 걸음부터.

작은 시작이지만, 꾸준히 이어나가보려 합니다.

```javascript
// 시작의 의지를 코드로 표현하면
function startBlog() {
  const motivation = "꾸준함";
  return `${motivation}이 핵심이다!`;
}

console.log(startBlog());
```

앞으로 잘 부탁드립니다! 🙏
